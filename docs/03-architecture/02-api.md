# API

#### 1. Сущности
**Карточка музыканта (Musician's card)**

| Поле        | Бизнес-описание                | Пример значения                   |
|-------------|--------------------------------|-----------------------------------|
| title       | Название группы                | "Muse"                            |
| description | Описание группы                | "Rock band from Teignmouth"       |
| message     | Сообщение группы               | "Скоро у нас концерт!"            |
| genre       | Жанры                          | "rock"                            |
| place       | Координаты места группы        | "long:48°42′31″N, lat:44°30′53″E" |
| streaming   | Ссылки на стриминговые сервисы | "appleMusic:https://..."          |
| visibility  | Статус карточки                | "public"                          |

#### 2. Бизнес-функции (методы)
**CRUDS для объявлений**
1. **`card.create`** - Создание новой карточки
   - *Бизнес-правило*: Только верифицированные компании могут создавать объявления
   - *Ограничения*: Название группы, жанр и местоположение на карте - обязательные поля

2. **`card.update`** - Обновление существующего объявления
   - *Бизнес-правило*: Только владелец может изменять объявление

3. **`card.read`** - Получение информации об объявлении

4. **`card.delete`** - Удаление объявления
   - *Бизнес-правило*: Удаление карточки приводит к удалению связанных с ней событий

5. **`card.search`** - Поиск объявлений
   - *Бизнес-логика*: Возвращает карточки с возможностью пагинации
   - *Фильтры*: По координатам на карте, по названию, по жанру

**Специальные методы**
6. **`card.offers`** - Поиск подходящих по вкусу групп
   - *Бизнес-логика*: Метод возвращает список групп на основе последних просмотренных/добавленных в понравившиеся
   - *Критерии совместимости*:
      - Соответствие жанрам
      - Географическая близость
      - Купленные показы групп
   - *Возвращает*: Список объявлений с оценкой релевантности (0-100%)

#### 3. Бизнес-правила

1. **Валидация жанров**:
   - Допустимые категории: "rock", "pop", "electronic" и другие, заранее прописанные
   - Новые категории требуют модерации

2. **Валидация стриминговых платформ**:  
   - Допустимые стриминговые платформы: "Spotify", "Apple Music", "Яндекс Музыка" и другие
   - Новые категории требуют модерации

3. **Формирование списка выводимых карточек**:
- Формирование списка карточек по географической близости так же должно учитывать масштаб карты и 
соответствующий вывод карточек на основе наличия у них платного продвижения

#### 4. Бизнес-метрики успеха
1. **Скорость подбора музыкальных**: 95% запросов должны возвращать результаты < 2 сек
2. **Точность соответствия**: Не менее 1% релевантных предложений групп для пользователей, приводящих к подписке на них
3. **Конверсия**: не менее 5% групп, купивших продвижение для более частого появления в предложенных группах и появления на карте на больших масштабах
